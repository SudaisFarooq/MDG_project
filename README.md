# Flood Prediction Using Geospatial Data

## Overview
This project predicts flood-prone areas using geospatial and environmental data. The aim is to assist in flood risk assessment and support better disaster management and planning.

## Features
- Flood risk prediction using machine learning
- Geospatial data analysis
- Interactive web interface
- Visualization of prediction results

## Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML/CSS

## Project Structure

data/          # Dataset files
models/        # Trained models
static/        # CSS, JavaScript, images
templates/     # HTML templates
app.py         # Main application
README.md      # Documentation


## How to Run

1. Clone the repository:
bash
git clone <https://github.com/SudaisFarooq/MDG_project.git>


2. Install dependencies:
bash
pip install -r requirements.txt


3. Run the application:
bash
python app.py
